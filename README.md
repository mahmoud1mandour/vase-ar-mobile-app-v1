Egyptian Heritage — Android app (Capacitor)

APK بالطريقة السهلة (Windows): شغّل build-apk.bat  → الناتج: android\app\build\outputs\apk\debug\app-debug.apk
بدون جهاز: ارفع المجلد على GitHub وافتح Actions > Build Android APK > Run workflow ونزّل egyptian-heritage-apk.
تجربة سريعة على المتصفح: npm install && npm run dev  (أو Live Server على index.html)
